# Wordmark refinement checklist

- [ ] Optical kerning adjusted pair by pair (not just metric kerning)
- [ ] Round letters overshoot the baseline and cap height slightly
- [ ] Stroke weights look even at small sizes
- [ ] Converted to outlines; no live font dependency
- [ ] Clear space defined (usually the height of a key letter)
- [ ] Minimum size defined for print and screen
- [ ] Exported: SVG, PNG @1x/@2x, PDF, in full color, black and white
